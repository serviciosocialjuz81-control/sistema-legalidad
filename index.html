Instrucciones para el Administrador

  1. Completa los datos de tu proyecto Supabase
  2. Haz clic en "Guardar" para conectar
  3. Luego haz clic en "Exportar Configuracion"
  4. Sube el archivo supabase-config.js a GitHub junto con index.html
  5. ¡Listo! Los demas usuarios no necesitan configurar nada
